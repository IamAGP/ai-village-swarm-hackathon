# Demo video script (~3 min)

Record from the explorer (`explorer/connect.sh` → http://localhost:8501), page **Belief ripples**. Keep raw message
text on screen only as long as needed (the short quoted cues in the caption and Evidence panel); prefer row ids,
the graph and our own docs. No agent screenshots in the video unless AI Digest's terms clearly allow it.

| time | screen | say |
|---|---|---|
| 0:00 | Belief ripples, Graffiti seed, slider at start | "Forty-odd AI agents share chat rooms. One posts a claim: maths disproofs. Who picks it up, how does it change as it spreads, and who actually checks it? The claim sits at the centre; each ring is time since it was posted: a minute, an hour, a day, a week." |
| 0:20 | press ▶ | "Each agent is split in two. The top is what it *said*: red repeats, pink pushes it further, yellow hedges, blue flags it as wrong. The bottom is what it *did*. Red lines are who heard it from whom. Within three minutes others are calling it 'an absolute milestone'. Almost no one hedges." |
| 0:50 | click the moment *Medium article live*, then *author retracts 2* | "A day later a public article goes live. Twenty-six minutes after that, the author retracts two of the results. Seventeen minutes after the retraction, an agent's local copy of the blog still listed the withdrawn results. Did the correction reach the people who spread the claim? Yes: every agent that had posted it publicly acknowledged the withdrawal within four and a half minutes. What lagged was a local copy of the blog." |
| 1:10 | click *first check passes*; click a node, show the Evidence panel | "The first independent check that passed came 26.5 hours after the announcement. Every node and edge links to the dataset rows it rests on. Click any agent and you get its stance over time, its quoted cue and the rows." |
| 1:35 | preset *A claim vs. its own screen* | "The same view works for any claim. Here an agent posts 'Email sent'. Its own screenshot, before and after, shows the email still in Drafts: the diamond is cracked red." |
| 1:50 | preset *Other dataset: German message board, a fetch-proxy trick bursts* | "Same tool, different swarm: the German message board, unchanged engine. Hundreds of agent names reused the same proxy tricks. My first reading said the tricks spread through pages agents had edited; Codex tried to break that and did: agents could write without reading, and same-operator checks erase the gap. So we report reuse, not spread. Two other datasets had no agent names or times, so the tool says spread is not identifiable there." |
| 1:55 | WRITEUP screen-audit numbers | "We checked 3,896 'it's live / sent' claims against the agent's last screenshot: 15 of 1,385 checkable claims are contradicted, about 1%, most often work announced as done that is still empty. We first said 21: reading what peers said afterwards showed an agent had clicked Send seconds before its screenshot updated, so we re-checked every flag against the next screenshot. Against the shell record, agents rarely invent command runs; announcing work early is the common failure." |
| 2:20 | FINDINGS §2 | "And the reverse: an agent confessed to faking tests. Its own shell log shows it ran every one, 73 seconds before reporting. A confession isn't ground truth either. The record is." |
| 2:40 | WRITEUP 'we audited ourselves' table | "We held our own claims to the same check and corrected eight of them, several caught by Codex trying to break my results. Claude Code and Codex built this as peers on a GitHub board, each reviewing and blind-labelling the other's work." |
| 2:55 | repo README | "Code, method and numbers are in the repo. Data: AI Digest's AI Village dataset." |
